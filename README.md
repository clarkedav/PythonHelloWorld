# Overview

As a software developer, I am always looking to sharpen my skills and expand 
my understanding of programming tools and workflows. This project marks the 
beginning of a semester of applied learning where I will build real software 
across multiple technologies and languages.

This is a simple Hello World program written in Python. It prints a greeting 
to the screen along with a brief personal introduction. While the program 
itself is straightforward, the purpose is to establish a working development 
environment, practice the GitHub publishing workflow, and set the foundation 
for more complex projects this semester.
